COMMON ISSUES & FIXES
════════════════════════════════════════════════════════════════════════════════

ISSUE: "Environment variables not set"
FIX: Create .env.local in project root with correct API keys

ISSUE: "Cannot find module '@supabase/ssr'"
FIX: Run "npm install" to install all dependencies

ISSUE: "RLS policy denied"
FIX: Set up RLS policies on Supabase (see RLS_POLICIES_COMPLETE.md)

ISSUE: "Connection refused" or "Cannot GET /"
FIX: Make sure "npm run dev" is running in terminal

ISSUE: "Port 3000 is already in use"
FIX: Run "npm run dev -- -p 3001" to use different port

ISSUE: "Cannot read property 'user' of null"
FIX: User is not authenticated - create account or login first
